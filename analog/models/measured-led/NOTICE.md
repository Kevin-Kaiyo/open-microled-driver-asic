Changes made here: selected `I-V.xlsx`, `Sheet1`, cells `A3:B102`, headed `20μm yellow`; retained original current in mA and voltage in V; added an A-unit current column and source row numbers; tested held-out interpolation; generated a piecewise-linear static SPICE representation from all 100 points. The additional `(0 V, 0 A)` knot and extrapolation are numerical extensions, not source measurements. All fitted coefficients, validation summaries and plots generated by this project are independent derivatives, not measurements made by this project.
