# A/B 与 VCSEL：从失效机理到改进边界

本阶段回应 2026-11-11 用户已确认的研究方向：MicroLED A/B 并行作为主线，VCSEL 独立推进；重点保留观察、假设、修改、反证、结果与代价的完整过程。C 暂缓，不据此判定 PAM4 路线不可行。

## 固定比较条件

MicroLED 延续上一阶段的黄色 20 µm 静态 I–V、200 fF 并联电容假设、1 Ω/0.5 nH 封装、200 ps 光学时间常数、1 GHz 接收极点、25/100 µA 直流目标、3.3 V 数字电源与 20 ps 外部输入边沿。新候选须独立通过直流两电平误差不超过 1% 的本阶段匹配门槛。预加重候选可能改变瞬态峰值和平均电流，须另列，不能把同直流目标称作同瞬态光功率预算。

VCSEL 保留 850 nm 研究模型、150 fF、0.5 Ω/0.2 nH、5 GHz 接收、3/7 mA 直流目标及 r10 的实际参考/供电电路；逐项修改输入阻抗、缓冲或换流晶体管。它不是蓝光 VCSEL 模型，也不是已拟合全部偏置、温度的器件模型。

统一实验帧为 4736 位，其中独立验证载荷 4096 位，净/线速率为 32/37。接收相位只由训练段选择。每个通过点须训练和验证零错、幅度余量 ≥7.5 µAeq、单侧时序余量 ≥0.37 线速率 bit UI，并满足端间电压、体结 ≤0.3 V 和静态模型电流域筛查。此为研究筛查，非 BER 或可靠性认证。

## 顺序与因果对照

1. 复跑已失败点并导出内部节点，保留旧版通过点作回归基线。
2. 分别缩短输入 RC、调整前置驱动，再验证输出负载电荷问题；每一组合修改都有单项对照。
3. 每个电路先做 DC0/DC1，真实晶体管重新求解每个速率；不压缩历史时间轴。
4. 对候选逐档扫速，至少给出最高通过测试点和相邻已测试失败点。边界附近减半最大时间步长。
5. 比较同吞吐条件的电源输入能量、返能、净能量及电流峰值；接收失败点不参加可靠交付能效排名。
6. 将成功与未成功的尝试写入新报告；保留原始网表、日志、波形及源文件哈希，完成阶段后同步 GitHub。
