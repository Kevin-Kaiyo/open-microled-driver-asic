# 为什么 MOS 切换很快，LED 的导电电流仍可能来不及建立

2026-10-19 · 单通道 NRZ 机理核对 · **解析计算，尚非新的瞬态仿真或光学测量**

## 1. 先看同一条静态 I–V 曲线要求的电压变化

来源为仓库中已归一化的 [实测静态 I–V CSV](../../../analog/models/measured-led/lin2026-yellow20-diamond-iv.csv)，上游是 Lin 等人的 20 µm 黄色 MicroLED 数据：[论文 DOI](https://doi.org/10.1038/s41467-026-74151-4)、[原始数据集 DOI](https://doi.org/10.5281/zenodo.20034288)。CSV 保存原 Excel 行号，以下均作相邻点线性插值；不是重新拟合了一个有温度、光学寿命或结电容参数的 LED 物理模型。

静态曲线的测量温度未报告。晶体管仿真的 27°C 不能自动变成 LED 曲线的测量温度。200 fF 是两路线共有的**假设常数电容**，没有从这份静态数据测得。

| 目标 LED 导电电流 | 插值得到的 VF | 5 V 电源下 LED_K 电压 | 经 1 Ω 后的 ASIC OUT 电压（DC） |
|---|---:|---:|---:|
| 25 µA | 3.361339464 V | 1.638660536 V | 1.638635536 V |
| 100 µA | 3.767909545 V | 1.232090455 V | 1.231990455 V |

LED 从 25 µA 到 100 µA，其正向电压需要增加 **0.406570081 V**。5 V 阳极固定时，这等价于阴极电压下降；其中 1 Ω 串联电阻造成的 DC 压降只有 25–100 µV。电感在 DC 下无压降，瞬态不能据此忽略它。

## 2. 微分电阻比 V/I 更能解释局部变化速度

这里使用 `rd = ΔV/ΔI`，不是工作点的 `VF/I`。在分段线性模型内，rd 是相邻两测量点间的精确斜率；实际器件的连续导数以及测量不确定度仍未知。

| 工作点 / 邻段 | 电流范围（µA） | VF 范围（V） | rd（kΩ） | rd × 200 fF（ns） | 原 Excel 行号 |
|---|---:|---:|---:|---:|---:|
| 25 µA / 前一段 | 21.65–24.61 | 3.32071–3.35714 | 12.307432 | 2.461486 | 45–46 |
| 25 µA / 工作点所在段 | 24.61–27.97 | 3.35714–3.39332 | 10.767857 | 2.153571 | 46–47 |
| 25 µA / 后一段 | 27.97–31.79 | 3.39332–3.43086 | 9.827225 | 1.965445 | 47–48 |
| 100 µA / 前一段 | 77.91–88.55 | 3.69762–3.73408 | 3.426692 | 0.685338 | 55–56 |
| 100 µA / 工作点所在段 | 88.55–100.65 | 3.73408–3.76983 | 2.954545 | 0.590909 | 56–57 |
| 100 µA / 后一段 | 100.65–114.40 | 3.76983–3.80550 | 2.594182 | 0.518836 | 57–58 |

因此，在 25 µA 附近，假设的局部 `rd·C` 时间尺度约 **2.153571 ns**；100 µA 附近约 **0.590909 ns**。这只是“静态分段斜率 + 假设 C”的局部小信号时间尺度，不是已测光学寿命，也不能直接换算成最大传送速率。

若仅考虑这个一阶子模型、且电流源输出电阻很大，小扰动的极点约为 `1/(2πrdC)`。实际驱动器输出阻抗、MOS 寄生电容、封装 R/L、载流子响应和接收器都会改变完整传递函数。

## 3. 75 µA 的转向增量会先分给哪条路径

明确电流正方向：LED 导电电流和并联电容电流均从阳极流向阴极；`I_pkg` 从阴极经封装支路流向 ASIC。LED_K 结点的关系是：

```text
I_pkg = I_LED,conductive + I_C
I_C   = C_LED · d(V_anode − V_cathode)/dt
```

当 B 路线从低态转到高态，基线支路保持约 25 µA，转向支路逐步送入约 75 µA。若先作理想电流阶跃近似，总下拉电流从 25 µA 到 100 µA；在切换刚发生时，LED 电压尚未改变，静态支路仍只流约 25 µA，其余约 75 µA 暂时流入电容。随着 VF 增大，LED 导电电流逐渐增加，电容分得的电流逐渐减少。

高态转低态时，LED 的 VF 不能瞬间下降。初始导电电流仍可能接近 100 µA，而下拉目标已减至 25 µA，此时电容电流为负，储能释放并推动阴极电压上升。因此，看到 MOS 支路电流已经改变，不能直接认为发光相关的导电电流已同步改变。

真实 9 MOS 电路还包含支路延迟、有限输出电阻和 MOS 电容。`基线 + 尾电流` 在转向瞬间未必严格恒定；准确的 KCL 需要包含这些位移电流。上面的式子对 LED_K 结点成立，不能把某一 MOS 沟道电流独自当成 LED 光输出。

### 电荷预算是时间尺度，不是严格的上升时间

```text
ΔQ = C · ΔVF
   = 200 fF × 0.406570081 V
   = 81.314016 fC

ΔQ / ΔI = 81.314016 fC / 75 µA
        = 1.084187 ns
```

**1.084187 ns 不是 10%–90% 上升时间。** 这个除法假设有恒定 75 µA 专门用于搬运全部电荷；实际电容电流会随着 LED 导电电流接近最终目标而减小，而且 10%–90% 是指定阈值之间的时间，不等于全幅电荷除以最初电流差。

为了说明这个区别，可建立一个明确简化的解析子模型：忽略 MOS、封装 R/L、其他电容和光学动态，仅使用同一条分段 I–V、200 fF 和瞬时到位的理想下拉电流。其方程是：

```text
C · dVF/dt = I_target − I_LED(VF)
```

以 **LED 导电电流** 的 25–100 µA 全跨度定义 10% 和 90%，阈值为 32.5 µA 与 92.5 µA。在每个分段积分后：

| 严格限定的解析子模型 | 阈值时间 |
|---|---:|
| 25→100 µA 理想电流阶跃，LED 导电电流 10%→90% | 1.883960 ns |
| 100→25 µA 理想电流阶跃，LED 导电电流 90%→10% | 2.744973 ns |

这些是**解析积分的结果**，不是 ngspice 对 9 MOS 电路的仿真结果，更不是光学上升／下降时间。下降较慢，来自低电流区更大的微分电阻；它解释了为何不能用一个固定 RC 或一个 ΔQ/ΔI 数字描述全部波形。完整电路的实际边沿仍应直接从统一瞬态轨迹测量。

分段公式（Ia < Ib）为：

```text
上升：Σ C·rd,k·ln[(I1 − Ia)/(I1 − Ib)]
下降：Σ C·rd,k·ln[(Ib − I0)/(Ia − I0)]
```

## 4. 为什么这也能区分电压驱动与电流转向

两路线具有相同 LED 和相同 81.314 fC 电荷变化需求，但它们向电容提供瞬态电流的方式不同。

- 电流转向路线的增量电流受到尾电流约束；在输出阻抗较高的局部近似下，LED 的 `rd·C` 很容易成为明显的建立时间尺度。
- 电压驱动路线的输出晶体管可以在切换边沿提供高于稳态电流差的瞬态充放电电流。忽略电感并线性化后，相关时间尺度更接近 `C·[rd || (Rdrive + Rpkg)]`；同时需要付出栅极驱动能量，检查峰值电流、供电回灌和端电压应力。
- 两条路线都不能绕过 LED 的载流子过程和完整光接收路径。即便电压驱动器迅速改变了 VF，静态 I–V 模型也没有证明真实光输出同样迅速。当前共同的光学／接收代理只是另加的设计假设。

因此，比较应关注“同一模型、同一接收规则下，哪部分拖慢波形、为改善它增加了什么能耗”，而不能把一个器件的开关延迟当成整条光链路的速度。

## 5. B 路线的互补信号具有结构性路径偏差

当前真实网表是 `GB = INV1(DATA)`，`GP = INV2(GB)`；ML 的栅极接 GP，MD 接 GB。GB 走一级，GP 走两级。

在**理想布尔传播延迟**的表达里，可以看见两种中间状态：

| DATA 转换 | 转换前 GP/GB | INV1 先变化后的 GP/GB | INV2 响应后 GP/GB | 可能的影响 |
|---|---|---|---|---|
| 0→1 | 0 / 1 | 0 / 0 | 1 / 0 | 两路可能暂时关闭；尾节点 VX 的储能及尾电流发生变化 |
| 1→0 | 1 / 0 | 1 / 1 | 0 / 1 | 两路可能暂时同时导通；75 µA 尾电流在两支路间分配 |

这张表是逻辑机理检查，**没有测出实际重叠／空档时长**。MOS 是否导通取决于 `VGS = Vgate − VX`、随体偏置变化的阈值、有限栅极斜率和当前漏端电压；反相器翻转阈值也不等于 ML/MD 的导通阈值。实际中间状态可能短于、长于或不同于布尔门延迟的直觉。

下一步应在同一次轨迹里联合观察 `GP、GB、VX、I_ML、I_MD、I_tail、I_LED,conductive`。不能仅用“GP/GB 是否高于 1.65 V”来宣布两管实际同时导通。当前两级结构用于暴露这类真实非理想效应；后续若设计平衡差分预驱动或受控非重叠时序，应按相同测量合同重新比较速度、功耗和应力。

## 6. 可复算记录

完整数值、原 Excel 行号、局部斜率、每段积分项和 CSV SHA-256 保存于 [mechanism-check.json](../../../evidence/highspeed-nrz/mechanism-check.json)。该文件明确标注分析类型，未加入尚未完成的最终统一瞬态数据。

下列仅使用 Python 标准库，从项目根目录可复算关键量：

```python
import bisect, csv, math
rows = list(csv.DictReader(open(
    "analog/models/measured-led/lin2026-yellow20-diamond-iv.csv")))
I = [float(r["current_A"]) for r in rows]
V = [float(r["voltage_V"]) for r in rows]
C, I0, I1 = 200e-15, 25e-6, 100e-6

def vf(q):
    k = bisect.bisect_right(I, q) - 1
    return V[k] + (q-I[k])*(V[k+1]-V[k])/(I[k+1]-I[k])

print("VF:", vf(I0), vf(I1))
print("DeltaQ, DeltaQ/DeltaI:", C*(vf(I1)-vf(I0)),
      C*(vf(I1)-vf(I0))/(I1-I0))
lo, hi = I0+.1*(I1-I0), I0+.9*(I1-I0)
knots = [lo] + [q for q in I if lo < q < hi] + [hi]
rise = fall = 0
for a, b in zip(knots, knots[1:]):
    rd = (vf(b)-vf(a))/(b-a)
    rise += C*rd*math.log((I1-a)/(I1-b))
    fall += C*rd*math.log((b-I0)/(a-I0))
print("Ideal current-step submodel only, seconds:", rise, fall)
```
