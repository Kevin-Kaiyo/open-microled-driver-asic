# 单通道 NRZ 比较：共同的测量约定

版本：2026-10-19。适用范围：电压驱动与电流转向的晶体管级 **pre-layout** 数值实验。此约定规定如何比较；单独拥有此文件不表示电路通过验证。

## 1. 先固定“同样的负载和接收条件”

两条路线使用相同的 20 µm 黄色 MicroLED 测得静态 I–V 曲线、5 V LED 电源、25 µA / 100 µA 的低 / 高目标电流、200 fF 并联结电容假设、1 Ω / 0.5 nH 串联封装寄生假设。它们采用同一组输入比特和 20 ps 输入转换时间。0.1、0.25、0.5、1、2、4、8 Gb/s 是待试验的输入速率，不是已达到的速率。

静态曲线来自 Lin 等人的公开源数据（[论文 DOI](https://doi.org/10.1038/s41467-026-74151-4)、[数据集 DOI](https://doi.org/10.5281/zenodo.20034288)）；来源、许可、适用域和哈希见仓库 `analog/models/measured-led/model-card.json` 与 `source-lock.json`。这条曲线提供的证据只支持静态电流—电压关系。200 fF、200 ps 光学时间常数、接收器带宽、封装 R/L **均是本实验的设计假设**，不是从该曲线测得，也不代表论文器件的完整高速模型。曲线测量温度未报告；没有器件离散性、热效应、复合噪声或真实光功率校准。

每条路线先校准自己的 DC 高、低电流并记录误差。共同接收门限固定为 **62.5 µA 等效电流**，共同归一化跨度固定为 **75 µA**。不能把每条路线自己失真的高低幅度重新拉伸至 0/1，再声称公平比较。DC 校准不等于动态眼图通过。

## 2. 从 LED 电流到接收判决

输入信号必须是流过测得静态 I–V 支路的 **导电电流** `i_LED`，不能把 200 fF 电容的位移电流也视作光输出。共用接收模型为：

`i_LED → 一阶光学/载流子代理 τopt = 200 ps → 一阶接收低通 fRX = 1 GHz → 固定门限判决`。

两个滤波器的 DC 增益均为 1，输出单位保留为“等效电流”。这相当于假定光输出对电流线性、光路增益恒定、接收器线性且无噪声；不含真实 LED 的 L–I、S21、光耦合损耗、PD 响应度、TIA 噪声、CDR 抖动和饱和。它用于在共同条件下比较电路导致的波形退化，不能生成物理 BER 或光链路认证。

`metrics.py` 在原始、不等间隔 SPICE 时间点上，按输入在相邻点间线性变化的假设，精确求解一个一阶滤波器：

`y[k] = a·y[k−1] + (1−a)·x[k−1] + β·(x[k]−x[k−1])`，

其中 `h=Δt/τ`、`a=exp(−h)`、`β=1−(1−a)/h`。很小的 h 使用级数避免相消误差。第二级对第一级输出作分段线性近似，因此仍需检查瞬态步长收敛。只有绘制眼图时才插值到均匀相位网格；增加插值点数不会增加证据带宽。

## 3. 训练与验证必须分开

本轮固定序列为：32 bit 交替预热 → 2 周期 PRBS7（254 bit）训练 → 1 周期 PRBS9（511 bit）独立验证 → 32 bit 交替尾部保护。PRBS 发生器、初值、位序和实际比特必须保存。训练和验证不能仅使用同一短周期的重复数据。

在 `t=0` 前以第一个比特对应的 DC 状态求工作点。第 k 比特的名义开始时刻为 `k·UI`；需要改变电平时，转换从 `k·UI` 开始，在 20 ps 后完成。所有路线使用同一约定。滤波器在初始 DC 值初始化，并处理整个连续轨迹；预热段不能从统计窗口偷偷删掉不利数据。

每条路线、每个速率，只允许在 PRBS7 训练段选择一次抽样延迟；延迟搜索范围为比特开始后的 0–max(4, ceil(3 ns/UI)) UI，网格为 1/128 UI。PRBS7 仍完整发送 254 bit，但训练评分裁掉末尾 ceil(max_delay_UI)+1 bit，保证最晚候选抽样时间早于验证段；其余尾部比特只作为时序保护。先最小化训练错误数，再最大化对固定 62.5 µA 门限的最小余量；近乎平坦的最优区间取中心。抽样延迟包含传播延迟和比特内相位，报告其秒值、整数 UI 延迟和模 1 UI 的相位。该训练是一个理想的时序对准程序，尚未实现硬件 CDR。

选定延迟后，对全部 511 bit PRBS9 **冻结门限、增益、抽样相位和延迟**。验证段不得重新选择最有利相位。允许使用各路线训练得到的不同延迟，是为了容许不同传播延迟；共同的接收滤波器、门限、训练规则和比特序列不变。

## 4. 眼图和“错误”的定义

- 固定抽样点的垂直眼开口：`min(y | bit=1) − max(y | bit=0)`，除以 75 µA 得归一化值。负值表示两类样本重叠。
- 固定门限余量：`min[min(y|1)−62.5 µA, 62.5 µA−max(y|0)]`。眼开口为正仍可能全部偏在门限一侧，因此两个量都必须保留。
- 错误数：511 个验证抽样点中，`y≥62.5 µA` 判为 1，与原始比特不同的数量。结果称 **无噪声有限序列判决错误**，不得简称实际 BER；0/511 不能支持 10⁻¹² BER 声称。
- 时序余量：在已经冻结的抽样点左右各扫描 0.5 UI，寻找包含该固定点、所有验证样本仍正确且余量为正的连续区间。报告左右余量和网格精度；到达扫描边界的结果是下界。扫描仅用于诊断，不重新优化验证点。固定点失败时，该点的时序余量记为 0。

本次预先设定比较筛查为：零错位、固定门限最小余量 / 75 µA ≥0.1、左右较小的时序余量 ≥0.1 UI。它与逐 MOS 的器件电压筛查分别报告。

最高通过的离散测试速率只能称“本模型、本测试点集合中的最高通过点”。真正的最大传送速率还依赖噪声、抖动、实测高速 LED 模型、PVT、版图与封装寄生、完整接收机和长序列误码测量。

## 5. 逐个电源端口核算能量

SPICE 电压源电流正方向流入其正端，因此源向电路交付的瞬时功率为 `p(t)=−v_source(t)·i_source(t)`。v 是电源两端的差分电压。能量积分保留不等间隔时间点，严格裁剪到相同的验证时间窗口；窗口端点线性插值，不外推。功率过零点显式插入，分别计算：

- 正向取能 `E_draw = ∫max(p,0)dt`；
- 回灌到理想电源的能量 `E_return = ∫max(−p,0)dt`；
- 净源能量 `E_net = E_draw−E_return`。

所有 DC 电源、输出级电源、缓冲电源和偏置源都要逐项列出再求和。理想 DATA / 互补 DATA / 时钟等输入源的取能与回灌独立列出，不能当成免费激励而隐藏。若电源会吸收能量，报告中不得把它自动当作能量回收效率为 100% 的真实稳压器；同时给出正向取能和净能量。未建模的上游稳压器、串行器、真实时钟、参考电压产生器、光接收机和散热功耗排除于本次晶体管边界，并显式列明。

本轮统一积分窗口为 PRBS9 的 **511 个输入 UI**，从验证第一个比特名义开始到该段名义结束；不要因路线传播延迟不同而平移供电积分窗口。接收样本可在末尾保护段内取得，而供电窗口保持一致。此窗口衡量输入端给定比特段期间的能量，存在有限序列首尾储能差，不能伪装为无限稳态或严格逐比特归因；应保留每源回灌、首尾电压及加长窗口敏感性。

每比特能量 `E/511` 使用毛数据位数（gross bits），不扣训练/FEC/编码开销，也不暗示所有失败速率具有可用吞吐量。只有满足本次确定性采样条件的点才可在受限比较图中标记为通过；失败点仍保留其功耗，帮助解释限制。

## 6. 实现接口与需要的验证

实现：`scripts/highspeed_nrz/metrics.py`。主要接口如下：

```python
import math

proxy = receiver_proxy(t, i_led_conductive_A)
max_delay_ui = max(4, math.ceil(3e-9 / UI))
# 254 bit 均已发送；评分时裁掉末尾，避免候选采样落入验证段。
train_score_bits = train_bits[:-(math.ceil(max_delay_ui) + 1)]
assert (32 + len(train_score_bits) - 1 + max_delay_ui) * UI < 286 * UI
sampler = train_sampler(t, proxy['receiver_proxy_A'], train_score_bits,
                        bit_start_s=32*UI, ui_s=UI,
                        max_delay_ui=max_delay_ui)
validation = evaluate_validation(t, proxy['receiver_proxy_A'], valid_bits,
                                 bit_start_s=286*UI, ui_s=UI, sampler=sampler)
rail = energy_window(t, v_rail_differential, i_voltage_source,
                     start_s=286*UI, end_s=797*UI, n_bits=511)
```

`eye_segments` 输出均匀相位的展示数据；`first_order_lowpass` 与 `integrate_window` 可独立检验。代码拒绝重复时间、非有限数值、没有两类比特的眼图和窗口外外推。导入 SPICE 轨迹时若存在重复时间，应按事先声明的规则去重并记录数量，不能静默改时间。

运行 `build/layout/venv/bin/python scripts/highspeed_nrz/metrics.py` 检查：不等间隔斜坡的一阶解析解、指数衰减、DC 增益、裁剪积分、回灌能量分解、带已知延迟的理想 NRZ 正例、反相比特负例和输入拒绝条件。这些是分析程序的数值对照，不是 MOS / LED 电路通过验证的证据。电路还须独立记录收敛状态、最大瞬态步长、实际高低电流、MOS 端口应力、限流/关断状态，并在通过/失败边界附近把步长减半复核。

## 7. 实际采用的数值控制

正式比较采用 Gear 二阶积分、reltol=1e-5、abstol=1e-13、vntol=1e-7、chgtol=1e-16；默认最大步长 UI/40。另以 UI/80、4 Gb/s 的 UI/200、1 Gb/s 的细步长梯形积分进行对照。更严格的早期容差曾在理想源的分段线性断点附近失败，诊断日志保留；放宽到上述值后与成功的严格解作完整窗口比较，详见 numerical-notes.md。数值求解完成不代表通信筛查通过。
