这是有单变量对照的筛查网格。工艺与温度、供电的交叉组合仍有未覆盖项。MOS 使用现有固定模型段，关闭统计变化。MicroLED 独立电阻库保持 `res_typical`。工艺段定义见 [GF180MCU 3.3 V/6 V Fixed Corner Models](https://gf180mcu-pdk.readthedocs.io/en/latest/analog/model_parameters/LV/LV_2_4.html)。

- A/B 的 VIN、VDD、VLED 按倍率同向变化，DATA 和 DISABLE 高电平随 VDD。独立 2.5 V VREF 保持名义值。20 µm 黄光 I–V、200 fF、1 Ω / 0.5 nH、200 ps 光学代理、1 GHz 接收条件固定。净 1.6 Gb/s；25/100 µA 直流目标各 ±1%。关断指令起算 20 ns 后导电电流绝对值 ≤0.1 µA，释放后 1 µs 内恢复，沿用应力和接收判据。
- VCSEL 的 VLASER、VDD、VREF、VPHY 按倍率同向变化。独立设定电压和外部命令电平保持上一轮条件。固定 850 nm 电气/光学代理、150 fF、0.5 Ω / 0.2 nH、5 GHz 接收条件。以净 8.8 Gb/s 为主、6.4 Gb/s 作速率对照，电流目标 3/7 mA 各 ±1%，沿用模型域、应力和接收判据。
- 完整帧 4736 线位、4096 评分有效载荷，20 ps 数据边沿。接收须同时满足零观察错、幅度 ≥7.5 µAeq、单侧时序 ≥0.37 UI。能耗按源实际正向交付能量 E+ 统计并另列返能及净能量，诊断短窗与完整帧的积分范围分别记录。
- 首先跑 DC 网格和短瞬态找因果线索。以实际器件修改或可实现的校准原型隔离假设。匹配前后网表和输入条件复跑，关键工况带回完整帧与关断/释放流程。短窗保留其实际初态、时间轴、评分长度和用途。
- 关断电流低于原 MicroLED I–V 的 0.1 µA 校准下界。两类发光器件均固定原模型，因此 `.temp` 结果反映建模驱动器及其 PDK 器件温度变化，光源本身的温漂、热耦合及光接收噪声需另行测量。
- 失败网表、日志、波形和身份保存在 `build/driver-pvt-20261117/`。报告公开可复现方法、压缩结果、示意图和判据，在验收后按阶段同步 GitHub 并验证远端原始证据。
