# 高速 NRZ 版图与 PEX：独立技术审阅

审阅日期：2026-10-20。本记录先审阅已有电路、测量约定、固定 PDK 和历史提取流程，再独立核对 `build/highspeed-nrz-layout/r3/{A,B}` 及修订的 `r4/{A,B}`。第 1–4 节是预审条件，第 5 节保留 r3 的故障，第 6 节核对 r4 的修正。未改动历史电路、模型或物理输出，也未运行 SPICE 数值实验。

## 1. 比较对象与应保留的边界

当前 A 为六管有限输出摆幅电压驱动，B 为九管电流转向驱动。两者使用 GF180MCU `nfet_03v3` / `pfet_03v3`；A 的 `VH/VL`、B 的电阻偏置和 dummy 支路实现不同，不能仅比较 LED 电流而忽略其供电。

沿用 [共同测量约定](../highspeed-nrz-20261019/measurement-contract.md)：测得的静态 LED I–V，加假设 200 fF / 1 Ω / 0.5 nH，固定 25/100 µA 目标、62.5 µA 判决门限、75 µA 归一化跨度；PRBS7 训练后冻结 PRBS9 验证。光学时间常数 200 ps 与 1 GHz 接收器是共同代理模型，PEX 不会使它们变成实测光学参数。

建议保留三个清楚命名的层次：

1. **既有原理图基线**：保留旧尺寸、偏置及手估扩散几何。
2. **按真实版图器件几何的控制组**：使用提取 W/L、A/P，但去掉布线 R/C，仅作归因对照。
3. **完整交付 PEX**：采用同一套器件和实际提取 R/C。

层次 2 可以区分“结面积改变”和“布线寄生改变”。其 R=0/C 省略只是控制组；不能替换正式 PEX 模型。若重新调偏置以恢复 25/100 µA，应另列重校准变体，不能把重校准收益归于版图寄生。

## 3. 单位、器件模型和残余不确定性

固定 `sm141064.ngspice:47042–47090` 的 `nfet_03v3/pfet_03v3` wrapper 直接传 W/L、A/P 给 BSIM，默认 A/P 为 0。米制调用中，`w=1u` 为 1 µm、`ad=0.6p` 为 0.6 µm²、`pd=3.2u` 为 3.2 µm。Magic `ext2spice scale off` 应输出明确物理单位；若有其他 scale 卡，必须确认不会二次缩放。这里的“p”是数值后缀 10⁻¹²，不是给 AD 指定电容单位。

GF 文档要求给 MOS 传**绘制尺寸**而非人工修正的有效沟道尺寸，模型自行处理有效尺寸：[GF180 MOS model limitations](https://gf180mcu-pdk.readthedocs.io/en/latest/analog/model_parameters/LV/LV_2_2.html)。使用公开固定模型并不等于其所有 GHz 小信号和封装条件已与硬件相关验证。

BSIM 内部源漏接入电阻与外部 diffusion/contact/metal R 的边界应保留 PDK 约定，不能为了提高速度擅自把 RDSW、NRD/NRS 或外部 R 设零。当前检查已确认 wrapper 默认 NRD/NRS=0，并且本地 deck 包含模型 RDSW；尚没有独立校准实验来量化所有内部/外部接入电阻分解误差，因此不声称完成寄生抽取的硬件校准。

RC 提取仍没有提供频率相关互感、趋肤效应、封装 S 参数或三维场求解的 sign-off。此前假设的 0.5 nH 封装电感不能与尚未提取的芯片电感混称同一证据。

## 4. 瞬态和能耗比较的审计条件

- **不重新缩放眼图**：用相同固定门限与跨度比较；列出 PEX 未重校准的 DC 误差。各路线可以按同一规则在训练集选延迟，验证集不能再选最优相位。
- **只用导电 LED 电流构造光学代理**：`VSENSE` 位于静态 LED 支路，不能误用同时含电容位移电流的 `LPKG` 电流。
- **采样实际 MOS 端点**：应力统计需要提取后的每只 D/G/S/B split node，包含热身、训练、验证和保护段。3.63 V 只是本项目的统一绝对端差筛查；body 正向偏压目前只有记录，没有二极管电流和可靠性验收标准。
- **逐源取能与回灌**：A 的 VH/VL 是可吸收电流的理想源。分别保留 draw / return / net；B 的参考、dummy、缓冲电源和 DATA 输入源同样计算。所有端口采用相同的 511 个输入 UI 窗口和 gross bit 分母。
- **不能把失败点能耗称为可用传输能效**：图中保留失败点功耗，但最高通过点只限本模型和预设离散速率集。0/511 是无噪声有限序列结果，不是实际 BER 规格。
- **收敛与物理效果分开**：PEX 在 RC 极点上可能迫使更小步长。通过/失败边界用相同路线、同一输入作步长减半复核；若修改容差、积分器或外加稳定元件，独立记录，不能将数值修复伪装成版图改善。

正式结果应同时给出未重校准 DC、眼开口/门限余量/时序余量、每源能量和回灌、器件端电压、步长对照及文件哈希。面积报告应标为单通道宏的几何范围，未包含 pad、ESD、稳压器、时钟/串行器、封装与光接收机时，不能称为完整产品芯片面积或能耗。

### 5.2 两项阻止定量 PEX 结论的电容输出问题

**CAP-01：原网络电容与拆分节点电容同时进入 RC。** r3 的 `.res.ext` 没有 `killnode`，原 `.ext` 的 node 电容仍保留，另加 rnode 电容。固定 Magic 源码 `resis/ResPrint.c:228–266` 在输出包含原节点名时不写 killnode；`extflat/EFread.c:454–464` 读 rnode 后进入 `efBuildNode`，`extflat/EFbuild.c:220` 对同名节点直接累加电容。这不是 MOS AD/AS 重复，而是互连电容输出与分配问题。

| 可直接从文本复算的量 | A | B |
|---|---:|---:|
| 原 `.ext` node-to-substrate C 合计 | 27.272521 fF | 29.495484 fF |
| `.res.ext` rnode C 合计 | 17.92112424 fF | 12.97969631 fF |
| 原 `.ext` 节点间耦合 C 合计 | 8.960560776 fF | 6.489850096 fF |

仅用这些总数还不能指定哪些分布项应如何移除；应先验证电容分配守恒，不能为追求速度或预期总量而任意删电容。非负电容、LVS 通过、全网 R 覆盖均不能证明这一问题不存在。

进一步的源码核查定位了 rnode 电容的来源：固定 `ResReadExt.c:521` 的 `ResReadNode` 不读取原节点的 substrate C；`ResRex.c:740` 启用 `ResOpt_Signal` 后，`ResReadExt.c:958` 的 `ResReadCapacitor` 将每项耦合 C 分别计入两个端点。因此上述 rnode 合计约等于耦合 C 总和的两倍，差异来自输出舍入；它不是从原 ground C 分拆出来的一份空间分布，也不是新增的物理结电容。

**CAP-02：hierarchy writer 将 MOS gate 电容当电阻 π 模型分配。** 在固定源码 `ext2spice/ext2hier.c:888`，`DEV_MSUBCKT` 进入共享 subckt 分支；`:983` 仅对 resistor tee 作特殊判断，但 `:1033` 的 else 对其余 subckt 也调用 `spcdevResPi`。后者在 `ext2spice.c:3905–3908` 将 gate 节点电容各半移至 S/D，然后清零 gate 电容。因此 r3 的 `readback/*_c.spice` 也不能直接充当正确纯 C 参考。

建议修复验证路径是：保持 r3 GDS 不变，在新目录、新 Magic 进程中明确导出 flat 模式；从原 `.ext` 与 `.res.ext` 的逐网络、逐元件账本验证电容归属和总量守恒，再重新生成 GEOM / C / RC 控制。保留 r3 原始输出作为诊断证据。报告中“所有 C 位于原始网络节点”的现有描述也需修订，因为 r3 事实上同时包含原节点 C 和 split-node C。

截至本次 r3 审阅，**连接和几何的证据成立，RC 电容定量有效性尚未通过**。不应据此发布最终速度、眼图或能耗结论；正在运行的轨迹可保留为诊断数据。完成修复后须对新哈希重新审阅，不能仅沿用本次拓扑通过状态。

## 6. r4：修正后的电容账本通过，空间分布仍须作为模型假设

独立结果与每对网络的目标电容保存在 [physical-r4.json](../../../evidence/highspeed-nrz-pex/audit/physical-r4.json)。本次检查直接读取实际 SPICE 和 `.ext`，用十进制数复算；通过**实际 R 连通分量**决定哪些 split node 属于同一网络，不依赖组装器所用的节点名前缀。A 得到 8 个逻辑网络，B 得到 9 个；没有网络被电阻误接成同一个分量。

修正模型保留 r3 的完整 R/MOS 网络和原 `.ext` 耦合 C，取原 `.ext` ground C 总量，按 `.res.ext` 内的归一化分配权重分配到拆分节点。原 `.res.ext` 电容数值不再被作为额外电容叠加。GDS、原 `.ext`、保留的原始 RC 文件与 r3 逐字节一致；RC 和 RCLUMP 的全部 R/MOS 行也一致。GEOM、C、RC 折叠后的器件模型、W/L 和 A/P 完全一致。本轮不是重新布局或重新调偏置。

| 独立账本核对 | A | B |
|---|---:|---:|
| 原 ground C 总量 | 27.272521 fF | 29.495484 fF |
| 原 coupling C 总量 | 8.960560776 fF | 6.489850096 fF |
| 两类显式 C 支路值合计 | 36.233081776 fF | 35.985334096 fF |
| RC 逐网络对最大差值 | 8.04 × 10⁻³¹ F | 1.013 × 10⁻³⁰ F |

### 6.1 分配权重的物理含义

`ResSimple.c:699–724` 先按几何 tile 面积分配临时电容，但后续 `:948` 调用之后仍继续简化电阻网络；例如 `:264–267` 会按电阻权重迁移被移除节点的分配量。因此最终 rnode 比例应称为**电阻网络简化后保留的归一化分配权重**。它们来源于几何计算，但并非独立测得的 GDS 面积比例，也不是三维电场求解得到的局部电容。

这是一套明确记账、可复现的 RC 组装近似，不能称为未经修改的原生 Magic RC 输出。逐网络对电容守恒只能证明未重复计数、未漏计和网络归属一致，不能单独证明 GHz 下的空间分布准确。

RCLUMP 控制保留相同完整 R/MOS，但把所有 ground C 放在原逻辑节点。它与 RC 具有相同折叠电容矩阵，可用于观察 ground C 位置假设的敏感性。两者的 coupling C 都放在原逻辑节点，因此这一对照**不覆盖耦合电容空间位置的不确定性**。即使两个结果接近，也不能据此推导 field solver 或硅后精度。

### 7.1 通过点与仍然失败的条件

在预声明的典型条件离散速率集 0.1 / 0.25 / 0.5 / 1 / 2 / 4 / 8 Gb/s 中：

- A 的 RC 模型在 0.1–2 Gb/s 的五个测试点通过；4 和 8 Gb/s 不通过。
- B 的 RC 模型只在 0.25 和 0.5 Gb/s 两个测试点通过。其最高已测试通过点为 0.5 Gb/s，不能写成“所有不高于 0.5 Gb/s 的速率均通过”。

B 在 0.1 Gb/s 的 511 个样本中没有错误，但固定训练相位的右侧时间余量只有 0.09375 UI，小于预设 0.1 UI。原 SCHEM、GEOM、C、RC 四组都出现这一低速失败，右余量分别为 0.09375、0.0859375、0.0859375、0.09375 UI，因此它不是本次 RC 新增的带宽回退。训练规则先最小化错误，再最大化竖直门限余量，没有优化水平居中；实际选中的延迟约为 1.008 UI。这是必须说明的采样算法边界。可以在后续独立实验中研究水平余量训练，但本次不应为改变结论而重选验证相位或改动冻结规则。

DC 典型条件下，未重调偏置的 RC 电流为：A 的低/高电平约 24.940 / 99.207 µA，B 约 24.986 / 99.709 µA。它们说明本次名义 DC 偏移较小，不能替代工艺角、温度和失配保证。

慢热条件下，A 的 2 Gb/s 为 64/511 错误；B 的 0.5 Gb/s 已有 2/511 错误。快冷 3.6 V 条件下，A/B 最大端差分别约为 3.725 / 3.764 V，均超过本项目 3.63 V 筛查线。即便某些快冷点的接收筛查通过，也不能据此声明器件应力合格。该筛查线本身也不是晶圆厂的可靠性签核标准。

### 7.2 独立源能量复算与数值敏感性

审阅者直接解压 A/B 的 RC 典型 1 Gb/s 原始波形，验证解压 SHA256，并用独立的分段三角形/梯形积分复算各电源和 DATA 的取能、回灌与净能量，包含窗口端点和功率过零。没有调用项目的能量函数。逐源结果与正式分析的最大差值小于 1.2 × 10⁻¹¹ fJ/gross bit，见 [raw-energy-samples.json](../../../evidence/highspeed-nrz-pex/audit/raw-energy-samples.json)。

| 1 Gb/s，RC 模型，全部源端口 | A | B |
|---|---:|---:|
| 正向取能 | 640.3 fJ/gross bit | 620.9 fJ/gross bit |
| 回灌 | 190.3 fJ/gross bit | 16.3 fJ/gross bit |
| 净能量 | 450.1 fJ/gross bit | 604.6 fJ/gross bit |
| 该点接收筛查 | 通过 | 失败：8/511 |

表中 B 的 1 Gb/s 能量是失败工作点的消耗，不是可用链路能效。A 的大量回灌进入可双向取能的理想源；不能假定未来电源能无损回收，也不能用净能量给两路线作省电排序。

UI/80 的步长对照没有改变所测 RC 筛查结果，能耗变化较小；但同时改变积分方法和更细步长的 1 Gb/s 对照，A/B 取能分别变化约 1.174% / 1.078%。报告应按这一数值敏感性保留适当有效数字，不应将亚百分比变化解释为已确认的物理收益。

RCLUMP 在 A/B 的 0.5、1、2 Gb/s 六个对照点均没有改变筛查结果，正向取能最大变化约 0.00398%，归一化门限余量最大变化约 0.0000199。在这些已测试条件下，ground C 分配位置的影响较小；该结论不涵盖耦合 C 的空间位置、工艺提取精度、真实光响应、接收器噪声或实际封装。
