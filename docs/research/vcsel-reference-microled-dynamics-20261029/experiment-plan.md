# 3.2 Gb/s 参考/供电改进与动态负载依据：实验约定

2026-10-29。目标为单个发光通道净吞吐 3.2 Gb/s。本轮完善 VCSEL 参考电流与供电，定位并处理慢热电流不足及快冷过冲；同步补充 MicroLED 动态负载的公开数据依据。暂不选择发光器件或 A/B/C 技术路线。

## 保留的比较条件

- 基线为提交 `74166165bc05cb7f090a38e50750209b31633f70` 中的 VCSEL 电路及其冻结原始记录，验收回执提交为 `8799ebf5b0110adad115a9e0bad1011ca0d3e4bf`。旧电路、模型、报告、失败结果不覆盖。
- 净载荷 4096 bit / 全帧 4736 bit；效率 32/37，线路 3.7 Gb/s，NRZ UI=270.270 ps，全帧 1.28 µs。训练评分 448 bit，另有 64 bit 保护；接收训练使用已冻结 v3 联合幅度/时间规则，验证段不得调参。
- VCSEL 保留 25°C 图读 I–V/P–I、150 fF 假设、封装 0.5 Ω/0.2 nH、原三阶动态代理和 5 GHz 接收代理；目标 3/7 mA。新精密参考不得暗中改变发光器件、接收门槛或光学效率。
- TT/SS/FF 沿用旧组合条件；额外拆分 MOS 角、温度、电源、电阻容差，避免把组合条件中的变化全部归为某一个因素。
- 判据仍为训练和验证无观察错误、最小有符号幅度距离 ≥7.5 µAeq、最小单侧时间余量 ≥100 ps；六种 MOS 端子对压差 ≤3.63 V、体结正偏 ≤0.3 V，联合图读静态域 2–7.5 mA。后两项为研究筛查，非晶圆厂可靠性签核。
- 参考/缓冲供电的修改应有单因素控制或充分节点证据；先 DC/短瞬态选择参数，再冻结同一设计的完整帧，不按每个角落分别重新校准。

## 能量与实物边界

对全部外部电源、输入、参考和新增辅助端口，使用原生时间样点、分段线性功率过零点积分：`E+=Σ∫max(Vport·Iin,0)dt/4096`。包括片内参考、缓冲、dummy 和负载损耗；每条新增供电必须进入清单。回送能量另报，不默认无损回收。

外部精密 VSET 可以作为系统接口，但其端口几乎不耗能不代表基准芯片自身零功耗。外部基准/电源内部、串行器、CDR、实际接收器等未实现部分必须单列，不将电路端口能量称为完整光链路能量。固定外部功耗的附加预算必须明示为假设，按 `P/Rnet` 折算。

新增反馈电路除稳态 OP，还应检查有限供电上升时的启动、进入稳态和至少一个参考/供电扰动。短帧接收与启动测量分开；启动期间越过图读域不得用于证明器件光学行为。

## MicroLED 动态模型

优先追溯当前黄色 20 µm 静态曲线的同一论文及开放原数据，再补充可区分电学 RC、载流子动态与测量链的来源。保留 200 fF / 200 ps / 1 GHz 基线；若没有同器件、相同偏置和测量基准，文献频响不得直接代替这些参数。明确 E–E、E–O、光功率/电压响应、dB 定义、温度、去嵌及不确定度。
