# MicroLED–Driver 联合验证计划

2026-10-29｜拟议实验协议；本轮只做可复算计算，没有新增晶体管、硅或光学通过结果。A/B/C 保持开放。

以[冻结动态契约](../../../evidence/microled-dynamic-20261029/response-contract.json)为起点：现有幅频属于原测量整链，缺相位且同像素身份未确定。旧 200 fF / 200 ps / RX 1 GHz baseline 保留；新数据只能建立新 model ID，再做 DC 校准与耦合回归。

## 固定分母与模型契约

单通道净 3.2 Gb/s：4736 bit＝64 warm＋448 training scoring＋64 guard＋4096 payload＋64 tail，效率 32/37，整帧 1.28 µs。训练仅取 `[64,512)`，guard 为 `[512,576)`，验证为 `[576,4672)`。NRZ 为 3.7 GBd，UI 270.27 ps、Nyquist 1.85 GHz；相同开销下 PAM4 为 1.85 GBd、UI 540.54 ps、Nyquist 0.925 GHz。Nyquist 是诊断频点，不能替代 BER。

每个样品记录 pixel/wafer/die ID、实际发光/注入面积、mesa 形状与周长、晶向、QW/势垒、接触/电极/钝化/封装版本；输入同像素 I–V、绝对 P–I、结温/环境温度、复数 S11/Z 与 S21 幅度和相位、小信号电压/电流、RF 幅度、暗态/噪声底、探测器/TIA/光路校准及去嵌文件，并保留不确定度。缺项不填拟合值。

候选模型为 `I(V,T,q)`、`ZLED(s,I,T)`、绝对静态 `P(I,T)` 与残余 `HEO(s,I,T)` 的一致组合；分别描述端口位移电流、导电/复合电流和光功率。联合拟合电学与电光，留出偏置/温度，检查因果、稳定、被动电学端口及参数相关性。不得由幅度推唯一相位；不得拟合整体 E–E 后再乘相同光学极点。[多寿命研究](https://arxiv.org/pdf/2310.17066)说明空间非均匀 MQW 需要检验单寿命假设，不能按 QW 数直接缩放寿命。ABC 微分寿命取 `1/(A+2Bn+3Cn²)`，不是稳态 `n/R`；PL 衰减测量的注入/空间分布不同，不能直接等同电注入微分寿命。ABC 辐射比例也不承诺带宽或出光效率。

## 分组 DOE

| 因素块 | 配对与扫描 | 必须控制的混杂 |
|---|---|---|
| 面积/侧壁 | 同外延 5/10/20/40 µm 正方形；等面积圆形；同面积电极/钝化 split | 同 I 与同 J 两套结果；实测有效面积、侧壁损伤、接触/电流扩展和光收集 |
| 外延/晶向/QW | 把材料成分、晶向、QW 数/厚度、势垒和工艺视为耦合 wafer block | 不将异片差异强拆成独立因果；匹配波长、温度、J 和接收器，报告未匹配项 |
| 偏置/温度 | 先复核 20 µm 的 25/50/75/100 µA；跨尺寸按同 J 重映射；建议 25/60/85°C | 先声明器件降额与结温上限；环境温度不能代替结温；温漂后重新测静态 |
| 重复/留出 | 每 split 建议至少 3 个独立像素，配对 wafer/die；留出偏置与温度 | 探索样本不证明良率；重复测量与独立器件分开计数 |

## 七阶段与 go/no-go

下表数值门槛均为**待冻结的研究建议**，不覆盖旧接收合同；应先按仪器重复性与误差预算收紧或修订。缺少校准只允许继续诊断，不进入性能认证。

| 阶段 | 操作与输出 | 进入下一阶段的判据 |
|---|---|---|
| 1 身份/DC/安全 | I–V/P–I、温度、尺寸、绝对功率和降额表 | 身份与参考面完整；安全极限缺失时不开展应力扫描 |
| 2 小信号分离 | electrical-only：Driver→校准 Z 负载；driver-bypass：已知源阻抗→LED→校准 RX；optical-only：校准光源→RX；最后 full-chain | 保存复数响应、噪声底、去嵌及 RF 幅度；幅度缩小一半后的归一化响应差建议≤0.5 dB，确认线性区 |
| 3 联合识别 | 比较单/多状态、偏置相关模型，留出验证 | 留出 I/P 误差建议≤5%，有效带内幅度≤1 dB、相位≤10°；须高于噪声底，残差无系统结构且参数可辨识，否则增加证据 |
| 4 大信号 | 多幅度阶跃、长短脉冲、过冲/电流尖峰、恢复尾巴、热瞬态 | 与留出瞬态一致；峰值 I/V、结温均在事先声明的降额内；电荷/能量守恒与数值收敛通过 |
| 5 公平晶体管比较 | 同器件/模型版本/净速率/光损耗/RX；A/B 为 NRZ，C 为 PAM4；短 PRBS 筛查后增加 PRBS15/31、独立 seed、长连码、抖动和供电/数据 skew | 训练后冻结相位、阈值、均衡与延迟；先复核旧合同的决策距离/时序，再给光接收结果；不在验证段重训练 |
| 6 BER/能量 | 同一绝对噪声模型/实测 RX，报告灵敏度、误码数与置信区间；前/后 FEC 分开 | 给定净吞吐与误码目标后评定；DSP/编码/FEC 的额外码率、延迟、训练和能耗全部入账 |
| 7 热/老化与封装 | DC、PRBS、热循环/老化前后重测 I–V/P–I/Z/S21；再检查互连与电极寄生 | 建议漂移≤5%且所有安全/RX门槛仍满足；时长/温度/失效定义须预注册。通过后再作版图联合验证，最后才考虑阵列扩展 |

## 统计与能量边界

在平稳独立误码假设下，零误码的单侧 95% 上界为 `1−0.05^(1/N)≈3/N`。0/4096 的上界约 `7.31×10⁻⁴`；拟议 BER≤10⁻¹² 需至少 2,995,732,273,553 个零误码有效 bit，净 3.2 Gb/s 下约 936 s。无噪声 SPICE 与复制同一确定性仿真波形不能据此认证；突发误码/漂移须另建统计设计。[NIST 精确二项式方法](https://www.itl.nist.gov/div898/handbook/prc/section2/prc241.htm)

`ELED=∫VLED·ILED dt/4096≈Vf·Iavg/Rnet`；3 V、100 µA 仅为 LED 电端口 0.09375 pJ/bit 示例。Driver 应逐端口报告正向/返回/净能量及排除项；闭合 TX 还需上游稳压/参考、时钟/串行器、编码/DSP/FEC。LED 若已由纳入的电源供能，不可再相加。完整链路另计 RX 与光损耗条件。

GaN TCAD 需极化、量子阱、输运/复合/光学模型与耦合校准；GF180 CMOS PDK 不能提供这些证据。制造只讨论工艺复杂度、接触/钝化/键合、容差及测试可达性，当前没有 foundry 成本/良率报价。
