# 3.2 Gb/s 单通道实验：范围与判据

日期：2026-10-27。用户明确选择单通道**净吞吐 3.2 Gb/s**。本轮为原理图晶体管仿真与模型诊断，不预选架构，不把新原理图继承为旧版图的 PEX 结果。

## 要回答的问题

1. MicroLED A/B/C 在此目标下，驱动输出、电气负载、光学代理和 RX 分别丢失多少余量？
2. 公开曲线能够约束怎样的 VCSEL 负载模型？哪些参数仍需假设与测量？
3. 带有限电阻参考、偏置支路和调制支路的 VCSEL 晶体管驱动，在同一实验净吞吐下有什么电气功耗、接收余量和局限？

## 固定条件

- 每帧 4736 线路 bit；payload 4096 bit；η=32/37。因此线路率 3.7 Gb/s，NRZ 3.7 GBd、PAM4 1.85 GBd；全帧 1.28 µs。
- A/B/C 保留原负载、电流目标、电源范围、v2 训练/验证分离；幅度 7.5 µA、单侧时间 100 ps 旧门槛不因失败而放宽。隔离对照明确标为非物理旁路实验。
- 训练评分 448 bit、训练保护 64 bit；验证 4096 bit；最多 8 ns 延迟搜索、5 ps 网格。离线搜索不是已实现的硬件 CDR。
- VCSEL 保留同一帧和训练方法。使用独立、预先固定的工作点和模型参数；光功率或归一化判决量的单位、阈值、噪声假设单独说明。不同光耦合、发射器和 RX 不足以支持跨器件能效排名。
- 能量按完整帧输入端口正向供能/4096 payload bit 报告，另列回送与净能量。外部源 IC 效率、RX、CDR、主机、FEC 尚未实现的部分明确排除。
- 零观察错误不证明 BER<10⁻¹²；本轮报告有限确定性帧的错误数以及有条件的噪声计算。

## 实施与验证

1. 先冻结输入、工具版本、PDK 子集和源码哈希；不修改旧结果。
2. A/B/C 目标速率 TT/慢热/快冷；相同波形上的光学/RX 旁路，以及独立电容对照。新增模型变体检查 DC 不变性；保存实际失败。
3. VCSEL 参数逐项关联到原图/正文或显式假设；独立检查 DC/频域，不称为原作者完整模型。
4. 实现偏置/调制电流的 MOS 支路及有限参考，校准后冻结；运行目标速率、低速、角落及必要数值/负载对照。
5. 以源网表连接绘图，以实际输出生成波形、余量、能量图；独立检查源/结果/图表一致性。
6. 更新中文研究报告，保存原始输出和 compact evidence。通过交付完整性检查后提交 Git，并将新原始证据归档到带 SHA-256 清单的 Release；回读验证后才称已备份。

## 不升级的证据层级

本轮不新增版图、DRC/LVS/PEX、RF 封装提取、光学实测、全链路 BER、产品安全或流片签核。诊断通过、仿真运行成功、接收门槛通过、芯片可制造是不同结论。
