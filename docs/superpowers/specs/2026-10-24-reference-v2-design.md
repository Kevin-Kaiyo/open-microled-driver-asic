# 显示 PWM 与高速 B：参考、供电和受控启动

用户授权：继续完善显示PWM参考源与受控启动，解决恢复时间与启动收敛；高速优先电流转向B的真实参考与供电，补参考电阻容差，保持各自负载和接收条件，以电路、版图和仿真更新独立报告。基线提交 `112ba95969ac6a2141c305324ea694e7b96c0765`。

## 范围与选择

1. PWM：从39MOS实际r5 PEX和上一轮故障网表追溯根因。区分电路环路/回流问题、理想引脚驱动的数值条件和统计网格。候选为改善参考环路动态、有限阻抗驱动与受控上电；100Ω/100nF继续作为恢复过慢的已知对照。不能只放宽求解容差、缩短观察窗或排除启动峰值。
2. NRZ B：从实际hv-r2/B核心开始。工程选择为外部精密电压基准输入、晶体管V-to-I反馈和晶体管稳压/缓冲网络，替换原理想VDUMMY和被动RREF电流设定。使用5V供电轨时计入其实际能量与扰动；不得在2.95V输入上假设无压差地产生3.3V。外部电压基准仍是系统边界，必须给误差、温漂和输出阻抗实验，不称片内自基准已实现。
3. 比较过的路线：继续纯RC滤波容易保留恢复折衷；自偏置beta reference已有明显PVT失败；直接扩展完整片内带隙会同时增加BJT物理流程与参考启动两个变量。本轮先落实可独立验证的模拟伺服/供电与受控启动。这些是工程实施选择，并非用户指定的器件规格。

## 固定条件

- PWM：原合成100µA LED、1MHz时钟、256µs帧、fault及恢复RTL、最小码电荷、启动保持期与原门槛，除明确版本化的受控启动电路外不变。20%峰值偏离/5µs恢复为继承研究预算，不是产品规范。
- NRZ：原20µm黄色LED静态模型、200fF、20ps输入、200ps光学代理、1GHz接收器、62.5µA门限、75µA跨度、冻结PRBS训练与511位判定；B目标点0.5Gb/s，接收判据不改。
- 原目录只读；新实验身份、执行源码、网表/日志/波形哈希独立保存，失败不删除。更改模型/参数后重跑DC与耦合回归。
- 不将外部元件参数、手估RC或旧核心PEX当成新模拟模块的实际版图提取。全片pad/ESD、实测光学、量产可靠性和统计良率不在本轮证据内。
