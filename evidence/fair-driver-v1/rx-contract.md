## 同一信息与帧开销

采用固定 PRBS15：初始状态 `0x5ACE`，输出状态 bit 14，反馈 bit 14 XOR bit 13，向左移位并限制为 15 bit，对应所声明的 `x^15+x^14+1` 序列生成约定。返回 `bits`、`symbols_N`、`symbols_C`，全部为普通 Python 列表。NRZ 的每一个符号承载一个 bit；PAM4 每两个 bit 按下表映射。

| D1D0 | PAM4 符号 | 目标导电电流 |
|---|---:|---:|
| 00 | 0 | 25 µA |
| 01 | 1 | 50 µA |
| 11 | 2 | 75 µA |
| 10 | 3 | 100 µA |

NRZ 目标电流为 25/100 µA。目标是共同激励电平，不能在分析时将实际失配归一化掉。

所有区间均为从零开始的 bit 下标，左闭右开。

| `ranges_bits` 字段 | 区间 | 长度 | 用途 |
|---|---|---:|---|
| `warmup` | `[0,64)` | 64 bit | 波形预热，非 payload |
| `training` | `[64,576)` | 512 bit | 训练总段，全部计入开销 |
| `training_scoring` | `[64,572)` | 508 bit | 只用此子段的标签与训练波形选采样时刻 |
| `validation` | `[576,4672)` | 4,096 bit | 独立验证，不能反向调参 |
| `tail` | `[4672,4736)` | 64 bit | 容纳延迟采样，非 payload |

`training_scoring` 是训练段的子集，不能重复计数。训练末 4 bit 是两种调制共同的保护区，保证最大 2 symbol 延迟的训练采样仍在验证段之前；训练时间余量计算也只读取验证起点之前的波形。训练总开销仍是 512 bit。

总帧 4,736 bit，payload 4,096 bit，开销 640 bit；`eta=4096/4736=32/37≈0.864864865`。净吞吐定义为整帧持续时间内传送的 payload bit 数，不把训练当作有效数据：

\[
R_{line}=R_{net}/\eta,\quad R_{s,NRZ}=R_{line},\quad R_{s,PAM4}=R_{line}/2,\quad T_{frame}=4096/R_{net}.
\]

例如净 0.5 Gb/s 时，线 bit 率为 0.578125 Gb/s，NRZ 为 0.578125 Gbaud，PAM4 为 0.2890625 Gbaud，整帧为 8.192 µs。这里只声明人工测试帧的开销，不能等同某个实际协议或声称包含 FEC。

验证段的 PAM4 四符号计数为 504/512/517/515，各占比接近 1/4；全部 12 种非自环有向转换均出现。返回的 `validation_PAM4_directed_transition_counts` 提供逐种计数。分析结果另含全部 16 种 PAM4 转换（含自环），NRZ 含全部 4 种转换；只数验证段内部的相邻符号，不跨训练/验证边界。

## 共同光学代理与接收极点

连续模型是两个串联的一阶环节：

\[
\tau_o\dot{x}=i_{LED}-x,\qquad \tau_r\dot{y}=x-y,
\quad \tau_o=200\text{ ps},\quad \tau_r=(2\pi\cdot1\text{ GHz})^{-1}.
\]

两级初态都取输入 `i_led_A[0]`，对应 t=0 已建立的 DC 工作点，不加入零初态造成的假启动。正式比较并非启动实验。滤波状态按原时间网格上的分段线性输入精确推进；采样值和阈值穿越时刻再由输出网格线性插值。返回的光学代理和 RX 输出仍是等效电流 A，不是光功率 W。这些共同极点不是从实测 LED 或接收器识别得到的模型。

正式 harness 预声明每 symbol 40 个最大时间步，并选取 80 步对照。分析保留 `proxy.max_input_step_ps`；滤波状态推进的解析形式不能免除输入波形离散误差与输出穿越插值误差的验证。

## 训练选相与冻结规则

固定门限：NRZ 为 62.5 µA；PAM4 为 37.5/62.5/87.5 µA。没有幅度重标定、自适应门限、均衡或验证段重新选相。

候选采样延迟为 `64/128,65/128,…,256/128` 个本路 symbol UI，即 0.5 到 2 symbol（含端点）共 193 个候选，两个调制都采用每 symbol 128 格。符号 j 的采样时刻是 `origin+(j+delay)*symbol_UI`。

评分首先最大化训练样本的最小**有符号、绝对电流判决余量**。对期望符号区间 `[L,U)`，余量为 `min(y−L,U−y)`，最外层缺失的一侧视为无穷远。正确区间内为正，跨错阈值为负。使用有符号余量是为了防止“远离阈值但已经判错”被误选为优点；另行输出普通无符号最近阈值距离供核对。

预声明的平台规则：与最大最小电流余量相差不超过 **1 pA = 10⁻⁶ µA** 的候选，只用训练评分段最大化最小绝对时间余量，再在完全相同时选择最早延迟。此规则在正式电路结果产生之前确定。时间余量的训练计算严格截断于验证起点之前，验证标签、验证采样值和验证时间余量都不参与选择。

增加此规则的原因是理想低速波形已经充分建立时，浮点末位差异会让单纯幅度评分选择平台末端。例如修正前理想 PAM4 的净 0.25 Gb/s 仅因选择末端而显示约 118 ps 时间余量；这不是电路带宽退化。固定 1 pA 平台规则后的回归见下表。它并不保证任意实际电路或有限相位网格的性能严格随速率单调，也不能从有限速率点推断连续 Fmax。

`sampling.training_scan` 保存所有 193 个候选的延迟、最小/平均有符号电流余量、错误计数、是否进入 1 pA 平台、以及平台候选的训练时间余量。非平台候选的时间余量为 `null`。`sampling.delay_symbol_UI` 是冻结的最终延迟；另列模 1 的相位和整 symbol 延迟。

## 独立验证指标与判定

验证固定 4,096 payload bit；NRZ 对应 4,096 symbol，PAM4 对应 2,048 symbol。PAM4 判决后按同一 Gray 表还原 bit；一个符号错误可能造成一个或两个 bit 错误。

- `validation.bit_errors` 和 `raw_errors` 均是原始 payload bit 错误数；`raw_BER=bit_errors/4096`。
- `symbol_errors`、`SER` 按符号计；错误位置从验证段零开始计，分别输出 bit 和 symbol 下标。
- `decision_distance_min_uA/mean_uA` 是对期望符号的有符号余量；`absolute_threshold_distance_min_uA/mean_uA` 是无符号最近门限距离，后者不能替代正确性判据。
- `horizontal_margin` 找每个冻结采样点到正确判决区间两侧最近阈值穿越的时间，取所有验证样本中的最小单边容许偏移；错误或恰在阈值的样本为零。分别输出左/右最小值、总最小 ps、本路 symbol UI 和 line bit UI。没有穿越的一侧以已观测帧端点为界。这里不是 peak-to-peak 开口，也不是实测抖动容限。
- `passed` 需要训练零 bit 错、验证零 bit 错、验证最小有符号余量 ≥ **7.5 µA**、最小单边绝对时间余量 ≥ **100 ps**，且预定非自环转换覆盖完整。PAM4 的较长 symbol UI 不会降低 100 ps 绝对门槛；两种 UI 归一化值只供解释。

`checks` 保留各项布尔结果，不能只摘取 `raw_BER=0` 宣称通过。有限确定性样本零错误不是 BER 认证。

## 可选的条件噪声估计

`conditional_noise_BER` 同时给出 σ=0.5/1/2/4 µA 的解析条件 BER/SER。假设冻结 RX 采样值上叠加独立、零均值、同单位的 Gaussian 等效电流噪声；保留波形中的确定性 ISI。逐样本积分落入各判决区间的 Gaussian 概率，并以 Gray bit 汉明距离加权计算 BER。使用 `erfc` 直接求尾概率，避免 `1−CDF` 在小概率时抵消为零。

这些是条件数学估计，没有晶体管噪声分析、shot noise、光子统计、时钟抖动、相关噪声、TIA 测量或 FEC 结果支撑；不是抽样实测 BER，也不作为本轮通过门槛。
