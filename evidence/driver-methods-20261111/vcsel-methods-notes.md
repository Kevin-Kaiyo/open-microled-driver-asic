# VCSEL 预驱动方法对照：2026-11-11

本轮发现：改善接收的关键不是简单增加前馈电容或降低门驱电源，而是消除现有两级 CMOS 缓冲链对短脉冲的压缩。把每路两级反相器改为单级、交叉接入互补数据，随后用输入电阻控制馈通尖峰，得到 69 MOS、150 Ω 的固定候选。名义净 6.4、7.2、8.0、8.8 Gb/s 均通过全部既定门槛；8.8 Gb/s 的半步长也通过。高于 8.8 Gb/s 尚未测试，不能称为器件或架构的最高速率。

这一结论只覆盖固定电路、固定模型、TT/25 °C、原理图级确定性仿真。没有新增版图、PEX、PVT、硅片或光学实测证据。原有 73 MOS 基线仍保留，所有失败实验也保留。

## 1. 共同实验条件

- 基线：`vc-atten50-steer20`，两级 CMOS 预驱动、两只换流 NMOS、反馈控制的偏置/调制电流源和实际 MOS 稳压器。
- VCSEL：850 nm 公开图线衍生的研究代理；相同静态/动态模型、150 fF 电容、0.5 Ω / 0.2 nH 封装条件；没有换成更快的光源。
- 接收：相同 5 GHz RX、一致的光学动态和归一化；训练段选择采样相位，验证段不调阈值或电路。
- 电流：低/高电平 DC 目标为 3/7 mA。候选 DC 为约 2.99975/6.99947 mA，误差远小于 1% 的固定门槛。
- 输入：外部互补源仍为 3.3 V、20 ps，原有各 50 Ω 外部源阻抗保留；新增工作没有加入不计能的理想门极源。
- 帧：4,736 线路位、4,096 个验证有效载荷位，净速率 = 线路速率 × 32/37。因此净 8.8 Gb/s 对应 10.175 GBd，而不是 8.8 GBd。
- 判据：零观察错误、最差幅度不低于 7.5 µAeq、单侧时间余量不低于 0.37 UI，以及端间应力、体结正偏不超过 0.3 V、导电电流保持在 2–7.5 mA 模型校准范围内。

µAeq 是接收分析的固定归一化量，不是实测光电二极管电流。2–7.5 mA 是模型使用范围，不是已证实的器件损坏阈值；越界意味着不能继续相信当前光学代理的外推结果，不能靠扩大门槛宣告成功。

## 2. 三种机制及其因果证据

### 小电容前馈：失败

在 DI→GP、DBI→GN 各加 20 fF，意图用已计能输入端提前提供栅电荷。7.2 Gb/s 的完整时间余量却从 0.33069 降到 0.15910 UI，幅度降到 8.49 µAeq，E+ 从 5.27402 增至 5.43370 pJ/尝试有效载荷位。6.4 Gb/s 也从通过变为时间余量 0.33246 UI 的失败。

原生波形表明，输入下降后 GP 提前由约 2.99 V 降至 2.584 V，但主缓冲器又把它拉回约 2.988 V。随后的输入边沿过早注入反向电荷，压缩了主路径本应产生的低脉冲：该窗口 GP 最低值由 0.351 升到 1.408 V，LED 低谷由 3.039 升到 3.940 mA。并非简单的“加电容就加快”。

不能把该现象写成已观察到双阈值穿越：同一验证时间窗内原版与前馈版的差分栅零交叉均为 2,058 次，未发现小于 0.25 UI 的额外近邻交叉。证据支持提前扰动、回拉和脉冲压缩。40 fF 条件对照因 20 fF 已明显恶化而取消，未扫参。 这只否定本次连接位置与时间关系，不是否定所有预加重方法；受控脉宽的有源预加重、输出电荷补偿仍需各自独立电路与完整计能验证。

### 降低真实门驱供轨：省能但接收变差

只把门驱稳压器 RDTOP 从 85 kΩ 改为 65 kΩ，使实际 DR 目标由约 3.1 V 降至约 2.45 V，原始 3.3 V 供电、光源供轨和 DC 电流目标保留。7.2 Gb/s 的 E+ 降至 5.03908 pJ，但出现 230 个验证错误，最差幅度 −4.37 µAeq。6.4 Gb/s 虽零错，时间余量仍只有 0.25992 UI。

原生波形显示，固定尺寸的第一级 PMOS 在较低供轨下，不能在短位周期内把 NP 充分充高。第二级因此不能完整拉低 GP；所示窗口 LED 低谷升至 4.887 mA。较低源功耗伴随着有效脉冲的丢失，这不是有效链路的能效提升。本轮没有把降低电压与尺寸连续扫参组合起来掩盖此因果对照。

### 单级交叉驱动：接收改善，但必须控制尖峰

从原电路删除 XBP1N/P 和 XBN1N/P 共 4 MOS；保留第二级 NMOS 12/0.28 µm、PMOS 24/0.28 µm。把 GP 反相器输入接 DBI，把 GN 反相器输入接 DI，保持 GP 跟随 D、GN 跟随 DB 的逻辑极性。实际供轨、偏置和换流器件保持原值。总数由 73 降为 69 MOS。

无额外阻尼的单级电路在 7.2 Gb/s 得到 0.44632 UI、31.79 µAeq、零错，但导电电流峰值达 7.58433 mA，超过模型校准范围；PMOS 漏体正偏 0.29816 V 也接近门槛。因此它没有通过总体判据。

只增大原有 RAD/RADB：50 Ω→100 Ω 时峰值降到 7.51551 mA，仍失败。由这两点得到局部斜率约 −1.376 µA/Ω，为保留约 50 µA 的名义模型域余量，计算得到追加约 47.6 Ω，随后只做一次 150 Ω 确认。预测峰值 7.44669 mA，实际 7.44753 mA；预测误差约 0.834 µA。此后固定 150 Ω，没有按不同速率或留出图样重新调电阻。

## 3. 同速率对照

| 净速率 | 原 73 MOS 时间余量 | 新 69 MOS + 150 Ω 时间余量 | 原 E+ | 新 E+ | 总体判据 |
|---|---:|---:|---:|---:|---|
| 6.4 Gb/s | 0.38104 UI | 0.46333 UI | 5.88021 pJ | 5.68495 pJ | 两者通过 |
| 7.2 Gb/s | 0.33069 UI | 0.44894 UI | 5.27402 pJ | 5.11332 pJ | 原失败，新通过 |
| 8.0 Gb/s | 0.23960 UI | 0.43444 UI | 4.76978 pJ | 4.65393 pJ | 原失败，新通过 |
| 8.8 Gb/s | 本轮没有同速原版点 | 0.43240 UI | — | 4.27545 pJ | 新版通过 |

E+ 是七个实例化源端口的正向供能除以 4,096 个尝试有效载荷位。失败点不能解释为已成功传输数据的能耗。6.4 Gb/s 两者均通过，有限帧源能量减少 3.3206%，是最直接的同速有效对照。

8.8 Gb/s 的最大步长由 UI/40 减为 UI/80 后仍通过，幅度 31.43768 µAeq、时间 0.432387 UI、E+ 4.2754316 pJ；相对 S40 能量变化 −0.000318%，时间变化约 −0.0000121 UI。电流峰值 7.47133 mA，体结峰值 0.26482 V。

## 4. 能量和接口代价

计能包括 VLASER、VDD、VREF、VD、VDB、VSET 和 VREGSET。69 MOS 候选在 7.2 Gb/s 的输入源峰值供电流约 7.411 mA，原版约 3.561 mA，约为原版的 2.08 倍。删掉一级缓冲减少了内部级间储能和延时，却让上游更直接地驱动较大的栅电容。总 pJ 略低并不意味着输入 PHY 更容易实现。 新版从 6.4 提升到 8.8 Gb/s 时，E+ 从 5.68495 降到 4.27545 pJ/位，但帧平均正向供电功率约由 36.384 升到 37.624 mW；单位位能耗下降不等于这一通道的总发热下降，也包含静态功耗被更高吞吐摊薄的效果。

VSET=0.15 V、VREGSET≈0.3263 V 仍是外部精密电压边界，不是已完成的 bandgap。外部参考/供电芯片内部损耗、发送端 PHY、时钟、接收器功耗没有完整计入系统能量；这不能当作完整光互连的墙插 pJ/bit。

显式储能也已核对。6.4 Gb/s 原版与新版的八个供轨/补偿电容分别释放约 282.2/176.6 pJ，新版少释放约 105.6 pJ，相当于源能量差 799.8 pJ 的 13.2%。这些是有限帧从 OP 初始化的能量记录。修正仅涉及列出的电容，不含全部 MOS 内部电荷、光源电容和电感，不是完整损耗平衡，也不是周期稳态能效。

## 5. 当前结论与下一步

该结果支持继续研究“更少级数、明确输入能力、受控边沿”的预驱动，不支持宣称 CMOS 缓冲越少越好，也不支持以此直接保证 32 Gb/s。最高通过点和真实最大速率不是同一个概念。

接下来应先验证真实输入 PHY/封装驱动能力、原理图到新版图的寄生差异、PVT 与供电扰动、长帧/重复图样的周期稳态、参考和供轨启动，以及更有实测依据的 VCSEL 动态模型。尤其是 8.8 Gb/s 的电流距离 7.5 mA 模型上界仅约 28 µA，不能据此宣称量产余量充分。
