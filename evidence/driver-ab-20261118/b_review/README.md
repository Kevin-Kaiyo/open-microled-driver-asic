# B 路线的独立核对

这里核对原 44 MOS 保护电路、W4/L2 单位电流镜与保护合并后的两个版本。三个观测条件为 TT27 标称普通帧、SS85 低电压故障双帧、FF−40 高电压故障双帧。文件名中的 `reference` 对应原保护电路，`intermediate` 对应栅电阻 220 kΩ、钳位电阻 200 kΩ、输入电容 10 fF 的 W4/L2 版本，`final` 对应钳位电阻改为 260 kΩ 的 W4/L2 版本。各文件的 `case` 字段指向实际原生网表。W6/L3 以及后续改变输入级和前馈支路的试验属于另行验证的电路。

**同窗比较。** 每组使用完全相同的源电压与阻抗、供电 RLC、DATA 和 DISABLE 的 PWL、LED I–V 模型、200 fF、1 Ω / 0.5 nH 以及瞬态求解选项。记录每个元件行、波形激励与负载文件的 SHA-256。故障时，外部数据继续翻转。首帧被主动关断的错误另行列出。普通帧比较 F1，故障比较恢复后的 F2，并沿用故障前 F1 的训练相位。

**从原生数据独立计分。** 用两个一阶滤波支路的加权差计算串联两极响应，在每个原生时间步对线性输入作解析积分。光学时间常数为 200 ps，接收器为 1 GHz，直流增益均为 1。训练仍在规定前缀和 1/64 UI 相位格点上选相位。每个 payload 位重新计算 62.5 µAeq 判决及至最近交点的两侧时宽。单侧下限 0.37 UI，幅度下限 7.5 µAeq。另从每个 MOS 四端重算六种端差峰值和体结正偏，并对全部七个外部电源端口分开积分正向取能、返还能量和净取能。10 fF 输入电容的帧首末储能变化单列，避免再次计入供电能量。实际校核使用原生采样点，报告中降采样的窗口用于绘图。

**慢角的失效边沿。** W4/L2 加 10 fF、钳位 200 kΩ 的 SS 恢复帧有 26 位低于时宽门槛。26 位均为“0”，前一个 62.5 µAeq 下降交点太靠近采样中心。4096 位均正确且幅度合格。码位 3511（从 0 计数，邻码 0110100）的左侧时宽为 0.365994 UI。全帧最小右侧时宽为 0.375741 UI。将采样再延迟 1/64 UI 会把右侧最小余量压至约 0.3601 UI。这项事后相位扰动只用于诊断。报告图在每条曲线各自的首帧相位对齐采样时刻，绿色区表示采样附近必须没有判决交点的区域。下降沿较晚解释了判决条件失效；具体晶体管或电容的贡献以独立改动和重测为准。

**W6/L3 的前馈电容试验。** 用相同的 W6/L3、关断时序、输入电容和 PRBS，仅将 GB 与 OUT 间的前馈电容从 31.275 fF 改为 36 fF。慢角故障后 F2 时宽不足的位数从 145 降到 22。原先 136 位受采样前的下降沿限制，9 位受采样后的上升沿限制。增大前馈后，前一类减至 0 位，后一类变为 22 位。码位 3511 的下降交点由采样中心左侧 0.35412 UI 移到 0.37920 UI。码位 2129 的上升交点在采样中心右侧仅有 0.36646 UI，仍低于 0.37 UI。两组均无幅度失败和判决错误。两个边沿对应不同的码位，并且采用各自首帧训练且冻结的相位。后续应针对上升与下降两种转换分别调整边沿，再用完整协议重测。

重新计分可在仓库根目录运行 `python3.12 scripts/driver_ab_20261118/b_review/check_stage.py`。若需定位一个慢角双帧的最差边沿，运行 `ss_timing.py <病例目录> <输出名>`。归档提供用于恢复这些数据的原生波形。电气模型、光学与接收器代理的确定性结果仍受模型范围、码型及有限观测长度限制。
