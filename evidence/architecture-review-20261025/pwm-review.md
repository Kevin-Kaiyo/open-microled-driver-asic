# 显示 PWM 性能与扩展边界只读复盘 · 2026-10-25

本次仅阅读已有 RTL、报告、JSON 和冻结波形，未运行 EDA / SPICE，未修改旧证据。最新选定对象是 2026-10-24 的 `c15`：原 39 MOS 实际 PEX，加板侧补偿 / 参考滤波及明确驱动、封装应力模型；不是 2026-10-13 的六管几何倍增电流范围实验。

**可直接回答用户：目前完成的是约 100 µA 恒流幅值、1 MHz 时隙时钟、256 µs 帧 / 3.90625 kHz PWM 重复频率、256 时隙的单像素电气研究。0.1–7 mA 可编程幅值、最大工作频率、多像素一致性和光学显示性能尚未建立。** 本轮的 27/27 电气 case 与三个局部环路点只证明所列条件通过，不等于完成所有灰度码、频率或阵列的联合验证。

## 2. PWM 时钟、帧、位深、量化及更新

| 项目 | 准确含义 | 源与证据层 |
|---|---|---|
| 时隙时钟 | 已用 **1 MHz**，周期 **1 µs**。 | `sim/safety/tb_safety.v:16`；物理数字 SDC `evidence/control-v3/pixel_control_v3.sdc:8` 的周期 1000 ns。 |
| 帧 | **256 个时隙，256 µs**。在固定 0<D<256 时，一帧一个连续脉冲；重复频率 **3906.25 Hz**。D=0 / 256 分别恒低 / 恒高，没有周期性 LED 开关脉冲。 | `rtl/pixel_pwm.v:3,11,17,26–36`；上述周期的算术推导。 |
| 位深 / 码数 | 8-bit counter；9-bit duty 接口用于表示 **0…256 共 257 个有效阈值**，包含精确全开。257…511 饱和到256。宜称“256时隙、约8-bit时间分辨率，另有全开端点”，不能称512级9-bit灰阶。 | `rtl/pixel_pwm.v:7,11–17`。 |
| 最短数字导通时间 | D=1 为 **1 µs**；D=255 留1 µs低时隙。 | `rtl/pixel_pwm.v:30–36`；`evidence/digital/rtl-selfcheck.log:2–3`。实际电流边沿 / 尾部另计。 |
| 理想量化 | 占空比步长 **1/256=0.390625%**；若100 µA矩形脉冲，平均电流步长 **0.390625 µA**。用户连续目标若由软件就近舍入，半LSB为0.1953125 µA；RTL本身只接收整数码。 | 由阈值和时隙数推导。不是 ADC/DAC 绝对精度，亦无 gamma / 光学校准证据。 |
| 普通亮度更新 | `duty`、`enable` 仅在 counter=255 的下一个上升沿采样，完整下一帧使用新值；帧内变动不会改当前脉冲。满足接口建立保持前提时，命令等待下一边界约0至不足256 µs。 | `rtl/pixel_pwm.v:26–36`。不是数据接口接收 / SPI 吞吐率或视频帧率规格。 |
| 输出是否组合直通 | PWM 是寄存器输出，比较 next_counter 后更新；slot0直接使用新提交输入，避免一周期延迟。 | `rtl/pixel_pwm.v:19–36`。 |
| 复位与故障优先级 | `rst` 是同步复位；普通 enable 仍按帧提交。FAULT 独立异步抑制，不等时钟 / 帧。恢复需 fault低、recover_request、高沿前 raw低，并有时钟沿。 | `rtl/pixel_pwm.v:19–25`；`rtl/safety/pixel_safety.v:15–24`。异步释放 / 亚稳仍有条件。 |

数字功能证据确实覆盖全部 257 有效码及 255 饱和码、帧中更新、enable、reset：518 帧、133159 次时隙检查，最短高 / 低均 1000 ns，见 `evidence/digital/rtl-selfcheck.log:1–4`、`gate-functional.log:1–4`。这些是 RTL / 功能网表证据，不是 257 码逐一经过最新模拟 PEX 后的光学线性或电荷 INL/DNL。新版物理 SDF 仅选 D=0、1、64、256 两帧并做保护测试，见 `scripts/control_v3/tb_sdf.v:24–49`。

**最大频率未知。** 已验证1 MHz工作点，不等于Fmax=1 MHz，也不能把寄存器 setup 余量986.059 ns代数反推为约72 MHz的产品上限。现有STA包含200 ns输入/输出延迟、约72.91 fF输出负载假设，跨宏连线未回灌；没有改变时钟后的全码、电荷、供电、瞬态和PVT频率扫描。9角 STA/SDF 通过的条件与限制见 `evidence/control-v3/summary.json:10–19,53–60`、`pixel_control_v3.sdc:8–33`。若只作架构计算，N位时隙计数有 `fPWM=fCLK/2^N`；这是设计权衡公式，不能直接提升频率或位深的验证等级。

## 3. 输入边沿、电流边沿、故障关闭是不同速度

最新 PWL RAW/FAULT/PERMIT 的 **10 ns 边沿、10 Ω输出阻抗是测试输入条件**，不是已测得的 LED 上升时间。最新名义故障从50.125 µs输入边沿起到总支路持续满足安全阈值约 **205.7768 ns**；首1 µs Q+=0.504896 pC、Q−=−7.363469 pC，后续保持低于1 nA。算法与范围见 `scripts/pwm_reference_v2/run.py:239–242`；数值见 `evidence/pwm-reference-v2/20261024/c15_fault.json:289–299`。

数字 `protected_monitor` 的9角 SDF 延迟 **0.767–2.429 ns**只是数字观测信号关断；它不包含模拟门、像素栅极和LED电荷释放。源：`evidence/control-v3/summary.json:14–17`。较早39MOS版本SS故障关闭303.39 ns是旧补偿/条件下的角落数据；不是最终c15故障最坏PVT规格，源：`docs/research/single-pixel-closure-20261015/report.md:159–171`。c15本轮没有重新给出全PVT故障最坏值。

### 已有波形的只读边沿后处理（本次新增观察，不是新增仿真验收）

读取 `build/pwm-reference-v2/20261024/c15_pwm/waveform.dat.gz`，先核对解压raw SHA：`1e1bebc663b26d32b0596383ec5919ac05b7ba31529c716070af62a8361a2431`，与 `evidence/pwm-reference-v2/20261024/c15_pwm.json:61` 相同。使用TT/27°C、D=1第二个稳定帧，原始PWL上升起点258.5 µs、下降起点259.5 µs。10%/90%阈值采用匹配DC=99.733511 µA；在各边沿后0.5 µs窗内取首次同方向穿越，按相邻采样点线性插值。

| 观测量 | 10→90%上升 | 90→10%下降 | 定义 / 限制 |
|---|---:|---:|---|
| 外部总支路 `i(VLEDLOAD)` | **6.381 ns** | **1.035 ns** | 含位移电流，先后有负尖峰与正过冲；不是建立到精度带的时间。 |
| 按既有脚本定义的导电分量 `@D[id]−@D[capcur]` | **14.371 ns** | **26.392 ns** | 模型分量的后处理，不是实测发光响应。该分量定义亦用于原生成器 `run.py:235,240`。 |

总支路50%交越分别在输入起点后9.146 / 9.736 ns。该波形总最大/最小为112.181 / −23.699 µA（`c15_pwm.json:44–45`），说明“稳态100 µA”和“瞬时峰值”也不能互换。当前case最大步长5 ns；求解器在实际交越附近自适应加细，总支路插值括区约0.00049–0.0153 ns，导电分量最长括区约1.12 ns。仍缺乏该正常PWM边沿的独立方法、PVT与完整频率包络，故只保留约数，不宣称ns级计量精度。

还有一个教学边界：正常PWM下降后，外部总支路最后大于1 nA约在3.071 µs后；按上述公式的导电分量尾部则更长，在下降后0.5 µs约0.534 µA、1.5 µs约0.172 µA。其电容分量会与外部端口电流部分抵消。**因此不能将205.8 ns的FAULT强制钳位关闭、普通PWM电流下降、总端口近零和光学熄灭画等号。** 原验收是完整帧的电支路电荷，并未建立光学黑电平或光学灰度串扰规格。

合成LED模型明确是N=3、RS=50 Ω、CJO=2 pF、TT=1 ns，无光学、热或老化模型：`analog/models/microled.spice:1–7`。不能用该TT参数、上述电流边沿或另一NRZ支线的带宽证明显示像素光带宽。

## 5. 39MOS面积、共享参考和阵列扩展

实际模拟测试宏GDS边界为 **637.03×200.36 µm≈0.127635 mm²**。包含参考10MOS、故障隔离5MOS、组合保护10MOS、LED钳位2MOS、像素开关/镜像6MOS、标准缓冲6MOS，总39MOS。源：`layout/startup_v3/startup_test_macro.spice:1–38`及其buffer include；真实提取计数39MOS/345R/288C见 `evidence/layout-v3/r5/summary.json:48–54`；尺寸与范围见 `docs/research/single-pixel-closure-20261015/report.md:150–154`。

39MOS不是完整产品晶体管数，也不是可以直接平铺的“最小像素单元”。数字PWM+恢复宏另有 **200×200 µm** floorplan；共同顶层跨度 **916×204 µm≈0.186864 mm²**，包含7277MOS（数字和官方fillcap也计入）。共同顶层全7277MOS动态回归尚未完成，模拟宏PEX+数字SDF回放不等于全顶层晶体管瞬态；源：`evidence/control-v3/summary.json:5–9`，`docs/research/single-pixel-closure-20261015/report.md:207–218`。面积均不含完整产品pad ring、ESD、seal ring等，且未优化阵列面积；不能从它直接推导显示pitch/PPI。

**共享参考在架构上可行，当前未做物理阵列证明。** 可让一个MREF建立VBIAS，再分配到多个输出栅，或使用独立镜像参考支路；如果将一个100µA源直接接16个并联MREF，电流会分流，不能获得16路各100µA。共享只使全局误差相关，不能消除局部失配、梯度、各LED VF/余量、IR drop、温度、PWM skew和LED光效差异。精确旧论述见 `docs/research/reference-safety-20261013/report.md:226–243`。

潜在可共享部分还包括全局时隙counter；每像素仍需自己的灰度状态、比较/门控和输出级。但本仓库未用当前39MOS/最终PCB网络验证共享bias的扇出上限、同时切换、阵列电源和局部校准，也没有当前参考源能驱动多少像素的数字。不能用旧单像素n=256 mismatch样本代替16像素同芯片分布，不能把共用reference当成光学均匀性保证。

## 6. 建议下一轮明确验收的问题（尚未执行）

1. **先固定显示规格及LED边界。** 区分峰值幅度范围、最低平均电流、所需灰度、刷新率、允许黑态/尾电荷和光学测量；若确需7mA，另立真实输出级和VLED余量目标，不沿用100µA结论。
2. **在单像素上建立频率与全码性能包络。** 在同一最终电路/实测可追溯负载下，检查D=0/1/邻码/255/256、Q–D单调性和INL/DNL、正常PWM关断尾部、PVT/阻容/包络时钟，之后才给Fmax和有效灰度位数；同时闭合输入同步、跨宏RC、reference-ready/欠压互锁。此列表是计划，不是已有结果。
3. **用小阵列回答共享问题。** 先定义同时切换和通道spread判据，再实际设计/提取共享参考与多像素网络，分开全局、局部、电源、LED和光学误差。只有完成这些工作后，才可讨论参考共享的面积收益和可扩像素数。

本文件所有建议均是本次只读复盘后的研究方向；不改变已冻结实验的判据或通过状态，不新增流片、硅、光学或制造可靠性声明。
